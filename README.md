## Installation
1. Install git
```bash
winget install --id Git.Git -e --source winget
```
or check
```url
https://git-scm.com/install/windows
```
2. Clone this repo
```bash
git clone https://github.com/MashiroX00/227b-2-project.git
```
3. install uv
```bash
winget install --id astral-sh.uv
```
or check
```url
https://docs.astral.sh/uv/
```
4. Change Workspace
```bash
cd ./227b-2-project
```
5. Sync dependencies
```bash
uv sync
```
6. Activate Visual Environment
``` bash
.\.venv\Scripts\activate
```
